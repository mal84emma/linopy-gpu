# cuOpt implementation harness record

> [!NOTE]
> The contents of this branch were generated by AI agents during an autonomous
> multi-agent run, supervised by the repository owner.

This orphan branch is the operating record of the autonomous multi-agent run
that produced the `feat/cuopt-solver` branch (first-class NVIDIA cuOpt support
for linopy). It shares no history with `master` and none of it belongs in the
linopy PR — it exists so colleagues can see **how** the change was built:
the charter the agents ran under, the competing plans, the frozen verification
contract, every review round, and the full run logs including the upstream
bugs found along the way (NVIDIA/cuopt#1768 and the B21 heap-corruption
diagnosis).

**Read first:** `PROJECT_LEAD.md` — the charter. Then `plans/FINAL.md` (the
selected implementation plan), `logs/15-verification.md` (the frozen
verification contract; its sha256 is recorded in two other logs),
`logs/00-lead-journal.md` (the chronological run record), and
`logs/50-review.md` (the review rounds).

The `/home/azureuser/...` absolute paths throughout are deliberate: they were
load-bearing instructions for the agents working on one specific machine, and
rewriting them would falsify the record.
